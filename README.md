# NeoGame

NeoGame is a modern online marketplace that connects gamers to buy and sell
in-game items, currencies, and game accounts safely and easily. The platform
provides a secure environment for trading digital assets across popular online
games, with a focus on trust, speed, and a smooth user experience.

## ✨ Features
- 🛒 Buy and sell in-game items and accounts
- 🔒 Secure transactions and escrow-style protection
- 👤 User profiles, ratings, and reviews
- 🔍 Advanced search and filtering by game, category, and price
- 💬 Real-time messaging between buyers and sellers
- 📊 Seller dashboard and listing management
- 🌐 Responsive, modern UI
